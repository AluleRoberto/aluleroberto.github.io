# Alule Robert — GitHub Pages website

Production-ready redesign of [alulerobert.me](https://alulerobert.me), built as a fully static Next.js site for GitHub Pages.

## Commands

- `npm ci` — install locked dependencies.
- `npm run dev` — local development server.
- `npm run build:github` — index uploaded resources and produce the static site in `out/`.
- `npm run build` — same production-static build, useful for local validation.

## Main routes

`/research/` · `/cv/` · `/biochemical-society/` · `/opportunities/` · `/resources/` · `/student-guide/` · `/credits/`

See `GITHUB_PAGES_GUIDE.md` for deployment/content instructions, `AUTOMATION.md` for the maintenance strategy, and `WEBSITE_BRIEF.md` for the corrected reusable master prompt.
